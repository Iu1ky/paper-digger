# Privacy Policy

Effective date: 2026-07-27

Paper Digger is a local, open-source collection of instructions and Python
utilities. It has no hosted backend, account system, telemetry, analytics, or
developer-operated data collection.

Paper Digger reads and writes files only through the permissions of the host
agent or the user running the `pd` CLI. The generated research workspace may
contain manuscripts, datasets, logs, and other sensitive material; users are
responsible for choosing an appropriate storage location and access policy.

Some workflow steps may ask the host agent to use web search, publisher sites,
academic APIs, MCP servers, SSH, or other third-party services. Those services
are optional, are not operated by Paper Digger, and are governed by their own
privacy terms. Paper Digger does not transmit data on its own.

Security or privacy reports should follow [SECURITY.md](SECURITY.md).
